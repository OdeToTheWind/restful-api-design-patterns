# Day 44 — Test Doubles & Coverage Discipline

Unit testing demonstrating dummies, stubs, spies, mocks, and fakes on checkout compensation flows, illustrating behavioral testing over raw line coverage.

## Quick Start

- **Default Port**: `3044` (Swagger docs at `http://localhost:3044/api/docs`)
- **Required Services**: None (in-memory)

```bash
cp .env.example .env
pnpm dev
```

## Testing & Quality

```bash
pnpm test:coverage
```
