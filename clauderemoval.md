## 3. Ongoing Maintenance: How Claude Works Without Adding Attributions

To ensure that future sessions with Claude Code do not introduce AI names or trailers, a two-tier safety mechanism is active:

### Layer 1: Private Local Instruction File (`CLAUDE.md`)
Claude Code reads `CLAUDE.md` in the repository root prior to every command.

- **Location**: Project root (`CLAUDE.md`)
- **Git Invisibility**: `CLAUDE.md` is listed in `.git/info/exclude`. Unlike `.gitignore`, `.git/info/exclude` is a local Git config file that is **never committed or pushed to GitHub**. The instruction file remains completely private.
- **Rules Enforced in `CLAUDE.md`**:
  - Never add `Co-Authored-By` or AI trailers to commit messages.
  - Never add `🤖 Generated with [Claude Code]` or bot badges to PR descriptions.
  - Never insert AI attributions or model references in code comments, docstrings, or markdown files.
  - Write all commits, PRs, and documentation from the perspective of **Bhargavi Badal**.

### Layer 2: Automated Git Hook (`.git/hooks/commit-msg`)
As a fail-safe, an executable Git hook is installed in `.git/hooks/commit-msg`:

```bash
#!/bin/sh
# Automatically strip Claude/AI co-author trailers and signatures
sed -i -E '/Co-Authored-By:.*(Claude|Anthropic)/Id' "$1"
sed -i -E '/(Generated with Claude|🤖 Generated with)/Id' "$1"
```

- Every time `git commit` runs (whether invoked by Claude Code, an IDE, or the terminal), this hook executes before the commit is written.
- It silently strips any co-author lines or bot signatures, ensuring that no commit with an AI trailer can ever be created.
